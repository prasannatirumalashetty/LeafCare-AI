# 🌿 LeafCare AI – Plant Disease Classification

AI-based plant leaf disease classification using TensorFlow and deep learning.

## 📌 About the Project

LeafCare AI is a deep learning project that classifies plant leaf images into different categories. It explores how artificial intelligence can help identify plant diseases from leaf images.

## ✨ Features

* Classifies plant leaf images into 38 categories.
* Uses a trained deep learning model.
* Supports image classification experiments.
* Provides a foundation for future plant disease detection applications.

## 🛠️ Technologies Used

* Python
* TensorFlow
* Keras
* Convolutional Neural Networks (CNN)
* NumPy
* Matplotlib
* Google Colab
* GitHub

## 📂 Project Files

* `LeafCare_AI_small.keras` — saved trained model.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open your project notebook in Google Colab.
3. Install the libraries required by your notebook.
4. Load the trained model using TensorFlow/Keras.
5. Prepare a leaf image using the same preprocessing used during training.
6. Run the model to obtain a prediction.
